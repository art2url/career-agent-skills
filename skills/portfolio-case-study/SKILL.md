# Portfolio Case Study

## Trigger

Use when the user wants to create case studies, build a portfolio, or design a creative resume that balances visual appeal with ATS compatibility.

Keywords: "case study", "portfolio case study", "portfolio", "write case study", "creative resume", "designer resume", "UX portfolio", "product design portfolio", "project writeup", "portfolio piece", "case study template", "design resume", "project showcase", "work samples", "portfolio website content", "how to write a case study"

## Part 1: Case Studies

### Structure

1. **Overview** — project name, your role, team, timeline, one-sentence impact
2. **Problem** — business context, user pain points, constraints, success metric
3. **Process** — research, options considered, key decisions and rationale
4. **Solution** — what you built/delivered, key features, how it solved the problem
5. **Results** — quantified outcomes (before/after table), business impact
6. **Learnings** — what worked, what you'd do differently

Target: 3-5 minute read.

### Depth by Role

- **Product Manager**: strategy, prioritization, stakeholder alignment, metrics
- **UX/Product Designer**: user research, design iterations, usability testing
- **Software Engineer**: architecture decisions, trade-offs, system design
- **Marketing**: channel strategy, targeting, creative, attribution

### Visual Elements

Must-have: before/after comparisons, key deliverable screenshots, results chart.
Always: blur sensitive data, add captions, size for mobile.

## Part 2: Creative Resume Strategy

### Two-Version Approach

**ATS version** (online applications):
- Single column, standard fonts, no graphics
- Show creativity through: clean typography hierarchy, strategic white space, strong writing
- Safe touches: subtle color in headers, hyperlinks to portfolio, clean dividers

**Designed version** (portfolio, networking, direct outreach):
- Your resume IS a design sample
- Consistent with portfolio site visual identity
- 2-3 colors max, 2 font families, clear hierarchy
- Must still be scannable in 6 seconds

### Field-Specific

- **Graphic designers**: Typography and layout precision demonstrate skill
- **UX designers**: Information architecture and scanability show thinking
- **Writers**: Impeccable copy with zero errors is the portfolio
- **Marketing**: On-brand identity and strategic content choices

### Portfolio Integration

Link resume to specific case studies:
```
- Redesigned checkout flow, reducing abandonment by 35%
  Case study: yourname.com/checkout
```

```
## Creative Resume Strategy

### ATS Version
[Content and format guidance]
```

## Rules

- Case studies show HOW and WHY, not just WHAT
- Your contributions must be clearly distinguishable from the team's
- Results need numbers — if you can't measure impact, measure activity
- Creative resumes must pass the 6-second scan test
- Never sacrifice content quality for visual design
